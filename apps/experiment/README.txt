RECONNECT EXPERIMENT — PORTABLE WINDOWS

1. Распакуйте ZIP целиком в локальную папку, доступную текущему пользователю
   для записи. Не запускайте приложение из ZIP, сетевой папки или OneDrive.
2. Запустите "Reconnect Experiment.exe". Установка и права администратора
   не нужны.
3. Выберите участника и протокол. Выполните LSL-проверку.
4. Убедитесь, что поток "Reconnect Markers" виден в LabRecorder, поставьте
   подтверждение и только затем нажмите "Начать сессию".

Протоколы читаются из protocols/*.json.
Данные автоматически и непрерывно пишутся в data/<participant>/<session>/.
Ошибки renderer, IPC и Rust записываются в diagnostics.jsonl рядом с exe.
При обращении в поддержку приложите этот файл.
Не переносите и не переименовывайте portable-папку во время записи.

Во время сессии:
  Ctrl+Shift+Space — пауза/продолжение.
  Ctrl+Shift+End   — аварийная остановка с сохранением частичных данных.

После окончания проверьте session.json: status должен быть "completed".
Статусы "aborted" и "interrupted" означают незавершённую запись.
